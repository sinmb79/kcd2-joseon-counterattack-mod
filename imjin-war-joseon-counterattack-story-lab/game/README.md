# 조선의 반격: 동래성의 새벽 웹 프로토타입

이 폴더는 초기에 만든 브라우저 프로토타입입니다. 현재 보스의 최종 요청은 실제 `Kingdom Come: Deliverance II` 설치 폴더에 모드를 적용하는 것이므로, 기본 실행은 프로젝트 루트의 `play_kcd2_joseon_mod.bat`를 사용합니다.

## 실행

KCD2 실제 모드를 실행하려면 프로젝트 루트에서:

```bat
..\play_kcd2_joseon_mod.bat
```

이 웹 프로토타입만 별도로 보고 싶다면 서버를 띄운 뒤 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:5174/
```

## 조작

- `WASD` 또는 방향키: 이동
- `Space`: 공격 또는 가까운 자원/피난민/봉화 상호작용
- `E`: 상호작용
- `Q`: 화차 배치
- 마우스 왼쪽 클릭: 공격
- 마우스 오른쪽 클릭: 화차 배치
- `R`: 현재 장 재시작
- `F`: 전체화면

## 현재 구현된 장

1. 부산진 급보
2. 동래성의 문
3. 반격의 씨앗

## 고정 설정

- 이순신 장군은 살아 있습니다.
- 시작 시점은 1592년 4월 부산진-동래성입니다.
- 중심 플레이는 지상전입니다.
- 원본 게임 이미지/음원/캐릭터 파일은 추출하지 않았고, 캔버스에서 직접 그린 팬픽용 이미지로 구현했습니다.
