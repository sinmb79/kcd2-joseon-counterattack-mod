# 게임 문체와 이미지 가이드

## 1. 목표 톤

전쟁 초기의 공포와 조선 반격의 씨앗을 함께 보여줍니다.

- 초반: 무너지는 성문, 급보, 피난민, 조총 연기
- 중반: 장부, 화약, 봉화대, 성문 수리
- 후반: 흩어진 사람들을 다시 묶는 반격의 씨앗

## 2. 이미지 원칙

원본 게임 이미지를 복제하지 않고, 다음 시각 언어를 직접 그립니다.

- 조선군: 청색/홍색 깃발, 원형 방패, 목재 화차
- 일본군: 흑색/적색 갑옷 실루엣, 조총 연기
- 민간인: 밝은 흰색/베이지색 의복
- 봉화대: 돌기단과 주황색 불꽃
- 성문: 검은 목재와 쇠못, 불탄 가장자리
- 자원: 화약 항아리, 목재 묶음, 군량 자루, 장계 두루마리

## 3. UI 문장

짧고 즉시 이해되는 문장을 씁니다.

- "장계를 살려라"
- "봉화 유지"
- "피난민 구출"
- "화차 준비"
- "이순신 생존"

## 4. 금지

- 이순신 사망 처리
- 노량 이후 설정
- 해상전 중심 플레이
- 공식 게임 이미지/음원/캐릭터 일러스트 복제
- 역사적 패전을 가볍게 뒤집는 완전승리 연출
