# 캐릭터 바이블: 초기전 버전

## 한도윤

- 소속: 동래부 병기고
- 역할: 플레이어 캐릭터
- 능력: 이동, 단궁/창 공격, 화차 배치, 성문 수리, 장계 전달
- 성격: 겁이 있지만 손이 빠르고, 병기가 사람을 살려야 한다고 믿습니다.

## 박연

- 소속: 동래부 하급 서리
- 역할: 자원/목표 안내
- 능력: 장부 상태, 군량, 피난민 수, 목표 지점을 알려줍니다.
- 성격: 전쟁을 숫자로 보지만, 숫자 뒤에 이름이 있음을 잊지 않으려 합니다.

## 윤서하

- 소속: 동래성 주변 피난민 네트워크
- 역할: 민간인 구출/숨은 자원 안내
- 능력: 샛길 표시, 피난민 이동 속도 증가
- 성격: 빠르고 현실적이며, 군대보다 민간인의 길을 더 잘 압니다.

## 송상현

- 소속: 동래부
- 역할: 2장 지휘 인물
- 사용 원칙: 역사적 항전의 상징으로 다루되 플레이어 조작 대상으로 만들지 않습니다.

## 정발

- 소속: 부산진
- 역할: 1장 역사적 배경과 급보의 출발점
- 사용 원칙: 부산진 붕괴의 무게를 전달합니다.

## 이순신

- 소속: 전라좌수영
- 역할: 생존 희망축
- 고정 조건: 죽지 않습니다. 사망 처리, 위장 사망, 노량 후반 설정은 사용하지 않습니다.
- 사용 방식: 봉화/장계/전략 정보로 연결합니다. 지상전 중심을 해치지 않도록 직접 전투 조작 캐릭터로 만들지 않습니다.

## 일본군 기능형 적

- 조총수: 원거리 압박
- 창병: 성문 돌파
- 사다리꾼: 성벽 접근 이벤트
- 보급장교: 3장 산길 매복 목표
