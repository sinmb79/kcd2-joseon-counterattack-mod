# 팬픽 게임 전장 규칙

## 1. 승리 조건

초기전의 역사는 조선의 패전으로 시작됩니다. 그래서 게임의 승리는 성을 완전히 지키는 것이 아니라 다음 반격의 기반을 살리는 것입니다.

승리 자원:

- 살아남은 피난민
- 보존한 장부
- 지킨 화약
- 전달한 장계
- 유지한 봉화

## 2. 지상전 중심

게임 내 주요 이미지는 다음입니다.

- 성문
- 사다리
- 조총 연기
- 화차
- 신기전
- 진흙길
- 봉화대
- 피난민 행렬
- 보급 수레

## 3. 이순신 생존 규칙

이순신 장군은 무조건 살아 있습니다.

플레이어가 실패해도 "이순신 사망" 같은 결과는 없습니다. 실패 결과는 장계 지연, 피난민 손실, 사기 하락, 반격 준비 지연으로 표현합니다.

## 4. 조선의 반격 컨셉 적용

게임 원본 데이터를 직접 추출하지 않고, 다음 컨셉을 직접 제작한 시스템으로 반영합니다.

- 장수/병기 조합 -> 스테이지별 지원 효과
- 제조/채집 -> 화약, 목재, 군량 수집
- 공성전 -> 성문 방어와 사다리 저지
- 반격 서사 -> 패전 속에서 다음 전투 자원을 보존

## 5. 공개/비공개 경계

- 설치 경로, 버전, 공개 기사 정보는 참고합니다.
- 공식 이미지, UI, 캐릭터 일러스트, 음원, 게임 파일은 복제하지 않습니다.
- 게임 내 비주얼은 캔버스에 직접 그린 오리지널 이미지로 대체합니다.
